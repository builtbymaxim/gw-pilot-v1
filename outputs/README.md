# Outputs

This directory contains artifacts generated by the pilot.

## Core files
-- `run_YYYY.json` – consolidated metrics for a given year. Top-level keys include:
  - `year` – report year.
  - `meta` – config hash, effective metric weights, and any warning messages.
  - `included_sections` – TCFD sections processed.
  - `section_wordcounts` – word counts per section.
  - `vui` – vagueness stats (`vui_hits`, `words`, `vui_per_1000`, `vui_norm`).
  - `spi_rule` – rule-based specificity counts and score.
  - `ai_spi` – NLI specificity results (`positives`, `evaluated`, `ai_spi`).
  - `spi_hybrid` – combined specificity used in the final score.
  - `ci_meta` / `ci_value` – carbon-intensity metadata and normalized value (may be null).
  - `gw` – aggregate score and risk band.
  - `per_section` – per-section metrics (`vui`, `spi_rule`, `words`, `count_sentences`).
  - `section_map` – pages per TCFD section with counts.
  - `regex_gate` – gating diagnostics (`total_sentences`, `gate_hits_count`, `gate_hits_sample`).
- `section_map_YYYY.json` – standalone `section_map` object.
- `regex_hits_YYYY.json` – standalone `regex_gate` object.
- `tau_calibration.json` – output of `calibrate_tau_cli.py` (fields: `tau`, `profile`, `auc`, `pr_auc`, `tpr`, `fpr`, `pr_curve`).

CSV tables and plots comparing issuers or years are also stored here.
